## 关键决定

- RPC连接关闭立即拒绝待处理请求，并向该次detached spawn的独立组发SIGTERM；继续检查整组而不只检查leader，750ms后升级SIGKILL，最多等待1500ms后释放stdio。仅使用所创建子进程的组ID，不扫描或终止其他进程。
- Agent退出先关闭App Server，再并发处理会话为interrupted。finish保存Promise可重复等待，正常关闭与断线错误区别处理。整体保存/清理等待2000ms；截止后中止未完成workspace请求并关闭SSE/HTTP，不等待turn/interrupt。
- 退出幂等，SIGINT/SIGTERM/SIGHUP监听器保留到退出，重复信号不会提前走默认退出路径。退出中的start拒绝重启。
- 不修改用户已授权的danger-full-access/never、MCP自动批准或文件访问行为，不增加依赖、公开接口或业务测试入口。
