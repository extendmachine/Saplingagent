## The key decision

- When the RPC connection is closed, the pending request is immediately rejected, and SIGTERM is sent to the independent group of the detached spawn; continue to check the whole group, not just the leader, upgrade SIGKILL after 750ms, and release stdio after up to 1500ms. Only use the group ID of the created subprocess, and do not scan or terminate other processes.
- Agent exits and closes the App Server first, and then the concurrent processing session is interrupted. Finish save Promise can wait repeatedly, and the normal shutdown is different from the disconnection error. Wait for 2000ms for overall save/cleanup; stop the incomplete workspace request and close SSE/HTTP after the deadline, and do not wait for turn/interrupt.
- Exit power, etc., SIGINT/SIGTERM/SIGHUP listener is retained to exit, and repeated signals will not go to the default exit path in advance. The start in the exit refuses to restart.
- Do not modify the user's authorized danger-full-access/never, MCP automatic approval or file access behavior, and do not add dependencies, public interfaces or business test entrances.
