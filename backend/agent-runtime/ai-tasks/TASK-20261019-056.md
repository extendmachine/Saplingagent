Agent file. Main attachments, page bridge, ports, engine selection and permissions
remain unchanged. Codex usage is bound to the confirmed current thread/turn and uses
last.totalTokens with modelContextWindow; never cumulative totals. Unavailable usage
is null, malformed counts are ignored, and explicit null plus valid values persist
through normal save and dirty-session recovery. Counts can decrease without a claim
that compaction occurred. Unsupported engines stay unknown.

existing same-origin/token and drain checks. Per-session writes serialize through
both disk and active-cache update. After the write, re-resolve and await the current
run so a completed/replaced turn cannot receive the update instead. Rename neither
cancels nor initiates inference. Old session records need no migration.
