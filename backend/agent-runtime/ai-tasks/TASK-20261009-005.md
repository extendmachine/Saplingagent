## 关键决定

1. 使用官方 Codex App Server 0.146.1 stdio JSON-RPC，项目CODEX_HOME，不自行模拟模型回复。本机模型目录实际返回5.6系列，选gpt-5.6-sol/medium；config首选不可用时回退目录默认。依赖Node≥24.11，本机26.4.0。
2. App Server长驻，threadId与session分离，SSE推送增量与工具状态；刷新snapshot及events恢复；去重requestId含未指定session的重试。同会话单轮，不因断网自动取消。
3. 1秒合并持久化、串行快照写入，终态落盘后done。服务重启恢复thread，磁盘遗留inProgress标interrupted；保存失败保留进程内dirty快照并报失败，不保证崩溃恢复未落盘尾部。
4. 关闭原生shell/电脑/浏览器/插件等执行能力，read-only沙箱；页面与Skills变更仅受控MCP。标准MCP form与确认式user-input通过聊天批准当次请求；原生shell/file审批拒绝。未知必填表单不静默接受。
5. 三个回环HTTP进程与stdio MCP，内部Bearer从私有文件读取；Host/Origin/cross-site拒绝越界，浏览器不获得token。日志仅元数据，30天保留；原始Codex stderr不落盘，Vite诊断仅终端。
6. 普通聊天和只读研究不更新公共任务索引。变更前project_context({modification:true})返回任务ID；全部五个写工具先回调Agent，将tool/规范化参数指纹匹配活跃App Server MCP item后登记，再执行handler。失败拒绝下游写入。Codex会过滤继承环境，必须通过mcp_servers.seedagent.env显式传项目目录、端口和managed标记。
7. 固定chat/main/依赖/后端/rules；可演进App/styles/features与Markdown Skills。候选固定TS/Vite CLI、AST路径保护和YAML验证，hash冲突拒绝覆盖。独立候选目录不等于OS/容器安全沙箱，前端组件仍同页运行。
