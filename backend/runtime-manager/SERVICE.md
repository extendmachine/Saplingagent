# Runtime manager

Owns application child-process lifecycle as the persistent parent launched by `scripts/dev.mjs`. Uses Node built-ins with no new npm dependency. `manager.mjs` supervises owned processes; `server.mjs` provides authenticated lifecycle control; `gateway.mjs` streams same-origin frontend/API/WebSocket traffic and provides the independent recovery page. Tests exercise real synthetic child processes, Git source transitions, HTTP gates, SSE and upgrades.

The gateway starts from configured frontPort5173 and manager control from4314; the unified launcher chooses available ascending ports for every service. Selected gateway/control ports survive complete restarts. Internal Vite starts from vitePort5174. Backends start workspace, builder, optional PDF (only if source exists), then Agent; Agent owns Codex App Server/MCP. Reverse-order shutdown only signals manager-created process groups. Full restart replaces frontend and backend; backend mode keeps frontend. Current checkout source and config are read again; manager code and ports need launcher restart. Busy work refuses preparation and releases acquired gates. Older source without drain support has the limits in CONTRACT.md.

Logs: logs/runtime-manager/runtime-manager-YYYY-MM-DD.log, lifecycle metadata only, 30-day retention. Child diagnostics stay in the terminal. Existing internal token is read from local-secrets; never returned to browsers. This service adds no directory restrictions, root access, automatic rollback, chat resend or inference.

## Windows x64 candidate (TASK-20261011-030)

Native Windows10/11 x64 uses the shared contracts/local-process.mjs OS contract. Project Node and native executable dependencies remain local. App Server uses codex.exe with file credential storage; OpenCode uses its selected opencode.exe, local XDG data/config/cache/state. The manager and command cancellation stop only their owned live PID trees with taskkill /PID /T /F; POSIX detached process-group behavior is retained. Windows shell commands use ComSpec cmd.exe /d /s /c, regardless of an inherited Git Bash SHELL. HTTP/SSE/permissions remain unchanged, including Full Access. Windows forced termination is abrupt; finish active operations before restart, and externally detached programs or forced parent death cannot guarantee cleanup. Native Windows10 auth/model/restart acceptance is pending; current host checks are macOS/synthetic. Start with bash Saplingagent.sh in Windows Git Bash; platform guide ../../docs/windows-install.html. No actual credentials, global environment or running production processes are changed by this candidate.
