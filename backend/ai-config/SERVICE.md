# Standalone AI configuration service

TASK-20261012-001 / Codex. Responsibilities: project-private provider schemes/keys/ledger, official Codex account flow, explicit model discovery and standalone setup lifecycle. Source server.mjs, store.mjs, auth.mjs, test/. Frontend lives in front/ai-config; shared file/transport contracts in contracts/ai-configuration.mjs and codex-rpc.mjs. The service does not host chat or change tool/file permissions.

Runtime Node24.21 in project .runtime, native built-ins only; existing pinned Codex0.146.1 used for auth. No npm service dependencies. Launcher builds existing React/Vite configuration entry into .cache/ai-config-ui, then starts `node backend/ai-config/server.mjs`; default OS-assigned loopback port. Ctrl+C or Finish setup stops only setup/owned auth. Public contract CONTRACT.md; deployment DEPLOY.md; official evidence REFERENCES.md. Runtime metadata stays in terminal (no credentials or raw upstream errors); this module introduces no persistent logs. Auth/keys/config/ledger under local-secrets/, ignored and excluded from distribution. Existing accounts and schemes are retained; blank keys preserve, explicitly replacing a key updates only that scheme. Anonymous custom local endpoints require noAuth selection.
