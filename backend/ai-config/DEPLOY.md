# Setup service deployment

Installed complete folder, Mac Terminal or Windows Git Bash. Run bash Saplingagent.sh; Configure AI builds front/ai-config using the project-local Vite and opens the configuration URL. Main chat need not be started or authenticated. `configure --no-open` prints the URL for manual opening. Keep terminal until Finish setup/Ctrl+C. Browser reload works on the same running service; reopen launcher after stopping it.

Choose ChatGPT browser/device login or save a custom Codex Responses/OpenCode Chat Completions/Responses/Anthropic scheme. Use provider API Base URL, model ID and your own API key; a marketing website is not an API endpoint. Save & use selects the default. Model discovery only runs on button press and never generates a prompt. Then Finish setup, Start app. Restart an existing app and start a new conversation to apply a newly selected scheme; old sessions stay bound to their engine. Do not reuse a saved Codex thread with a different configured provider.

Credentials are local-secrets/ files; no global accounts/config imported or replaced. A saved configuration is not a successful remote/model test. Actual login/Windows/provider tool streaming remain human acceptance. Roll back source through Git without deleting local-secrets/ or conversations; return to old-compatible saved scheme before running older sources. Stale writer lock local-secrets/ai-config/write.lock may only be removed after confirming no setup process is running. Preserve malformed files and repair them explicitly. New service is demand-started; no production services are restarted by setup.
