Conversation controls and context reporting

Session snapshots and workspace patches accept optional contextUsage: {usedTokens, contextWindow, updatedAt} | null. Omitted data remains unchanged; null means unknown. Counts can fall after provider context reduction. OpenCode/Claude without this report remain unknown. The gauge does not promise a compaction threshold.
