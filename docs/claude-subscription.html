Use your own Claude subscription token locally

Choose Claude → Subscription token (personal use) in the setup website. This is a manually supplied credential for the official Claude runtime. It is separate from an Anthropic API key and from importing an account file.

Configure

  1. In a terminal with the official Claude Code CLI available, run:
    claude setup-token
    Complete the official browser authorization yourself. If the command is unavailable, follow the official CLI installation guide.
  2. Open Saplingagent configuration, save the project settings, select Claude and then Subscription token (personal use).
  3. Enter a scheme name, paste the token into the password field, and enter a Claude model ID available to your account. This option has no custom API URL, anonymous-auth checkbox or model-catalog request.
  4. Choose Save & use, finish the normal save/build configuration flow and start or restart the app. Use a new conversation after changing the engine or model.

Saving confirms local storage only. It sends no model request and does not verify expiry, access, quota or network availability.

Storage and renewal

Each scheme keeps its token as oauthToken in an ignored local-secrets/api-keys/ai-<scheme-id>.json file, with a reference in the credential ledger. Public configuration returns only whether a credential is present. Saved tokens are never filled back into browser fields.

Leave the token field empty to retain an existing token for the same subscription scheme. Switching between API and subscription authentication requires a new credential. To renew an expired or revoked token, run the official command again, edit the scheme and save the replacement. Saplingagent does not copy a global login file or refresh the token automatically.

Scope and limits

This option is for the account owner's local use through the unmodified official SDK/CLI. It does not establish Anthropic approval for a third-party product, shared accounts or hosted routing. Account eligibility, usage limits and charges remain subject to Anthropic's current conditions. Use an API scheme for integrations that require API authentication.

The Claude process receives CLAUDE_CODE_OAUTH_TOKEN rather than an API key or custom endpoint. Full Access remains the current OS user's access; local credential storage is not a sandbox that prevents authorized tools from reading project files.
