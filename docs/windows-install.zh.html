Saplingagent Windows 安装与配置

版本0.9.2，独立内核0.91 / schema3。新用户获取 release 快照，不包含 Git，也不初始化仓库、不连接远端、不选择存放方式。

安装

macOS 使用终端；Windows10/11 x64 或 ARM64 先安装 Git for Windows，使用 Git Bash。CMD / PowerShell 不能直接运行 Bash；WSL/Linux 不属于此安装路径。macOS 支持13.5+，自动识别 Intel / Apple Silicon。运行时与依赖均安装在应用目录。

curl -fsSL https://raw.githubusercontent.com/extendmachine/Saplingagent/release/install.sh | bash -s -- --lang zh

或下载 release ZIP，解压后运行：

bash Saplingagent.sh --lang zh
  1. 1 安装 / 修复依赖：仅安装本地依赖，保留应用源码和已有 Git。
  2. 2 配置 AI 接口：打开独立网页，选择自己的 Codex 账号或 Codex / OpenCode / Claude API；支持自定义 API 地址。Codex 可读取本机文件登录或上传 auth.json；Claude 仅导入 API 凭据，不导入订阅登录。
  3. 3 启动应用；使用实际打印的网址，端口占用会顺延。4 服务诊断；6 内核管理；9 切换语言；0 退出。

网页未自动打开可使用 bash Saplingagent.sh configure --no-open，再打开终端网址。登录、模型、额度和网络由用户自己的服务决定。

网页升级内核

右上角 Kernel → Check for kernel update → Upgrade kernel & restart。独立进度页会在原服务停止后继续完成备份、内核替换、内核依赖修复和完整重启；成功后跳转实际端口。应用页面、MCP、Skills、自定义服务、应用依赖声明、数据、凭据和已有 Git 保留。失败可显式重试或手动恢复，不自动回退。

从0.9.1过渡

旧 schema2 不能直接跨边界升级。请下载0.9.2到新目录，保留原目录，再有选择迁移自己的应用/数据/配置；不要覆盖真实凭据或重建旧目录基线。之后兼容的 schema3 内核可在网页升级。
