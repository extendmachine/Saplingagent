Windows 安装 Saplingagent

适用系统

主要目标是已更新的 Windows 10 1809+ Intel/AMD 64 位（建议 19045），PowerShell 5.1 或更新版本；也支持以 Windows 11 x64 或 ARM64 为测试目标。安装时自动检测原生 x64 或 ARM64 架构，无需手动选择；不支持 32 位 Windows。需要可写的本地文件夹，以及 Node、npm 和模型服务商的网络访问。当前开发验证在 Mac 上完成，Windows 真机验收仍待进行。

安装、配置和启动

  1. 解压整个项目文件夹，不要直接在 ZIP 内运行。
  2. 在项目文件夹打开 Git Bash。
  3. 运行下面的命令，选择中文。
  4. 依次选择「安装 / 更新」→「配置 AI 接口」→ 网页账号或 API 配置 →「启动应用」。
bash Saplingagent.sh --lang zh

配置 AI 接口会打开独立网页，可登录 ChatGPT 或保存多个服务商方案、自定义 API 网址、密钥和模型。保存默认 OpenCode 或自定义 Codex API 方案后，启动无需另行登录 ChatGPT。保持终端窗口打开；网页默认 http://127.0.0.1:5173/。正常停止请按 Control+C。

文件和账号

Node24.21.0 校验官方 SHA-256 后安装到 .runtime/；Codex0.146.1、OpenCode1.19.0 和锁定依赖也安装在项目内。无需 WSL、全局 Node 或 Codex 桌面应用。不修改系统 PATH、注册表或永久执行策略；请使用 Git for Windows 自带的 Git Bash；Windows 系统工具由 .sh 内部调用，不需要手动执行 PowerShell。

使用自己的模型账号；登录不等于免费或保证额度。Codex 凭据在 local-secrets/codex/，OpenCode 在 local-secrets/opencode/。权限保持当前系统用户 Full Access，不新增目录保护、不提升管理员权限。分发时必须复制完整文件夹，单独复制 .sh 不够。

切换版本和重启

Windows 安装需要 Git for Windows 提供的 Git Bash；聊天不要求创建 Git 仓库，分支和版本控制需要实际 Git 仓库。ZIP 源包没有 Git 历史和三个开发分支，需要测试切换时请使用 Git 检出目录。先选择版本，再点击 Restart app；Restart backend 保留前端。故障恢复页面为 /__saplingagent/runtime。

请先完成正在进行的对话和写入。Windows 使用本次启动进程的 PID 树停止服务，属于强制结束；不能撤销已发生的副作用。强制关闭父进程、断电或另行脱离的程序不能保证清理。修改启动器、管理器或端口时，要退出终端中的服务并重新启动。

排错和真机验证

诊断使用 doctor；修复安装使用 install --repair；设备码登录使用 login --device-auth。安装被打断后，确认安装进程已经停止，再删除残留的 .runtime/windows-node.lock 或 windows-install.lock，重新安装。建议较短的本地路径，避免 Windows 路径长度问题。

请在 Windows10 真机依次验证：安装、登录、发送和停止消息、刷新恢复、配置 OpenCode、修改一个临时应用文件、切换 Git 版本并重启前后端。这些真实模型步骤尚未在当前 Mac 环境执行。

安装前出现退出码 150

旧菜单可能在后台启动 Windows 终端桥接，导致尚未检测设备就被终端控制信号停止。新版 Windows 操作在前台执行，安装和诊断直接启动 PowerShell。请更新完整项目文件夹再重试。应先看到“正在启动 Windows install（PowerShell）”，再看到“Windows 安装器已启动”，然后检测设备。若仍失败，在 Git Bash 运行 bash Saplingagent.sh --lang zh install，保留此前的启动和错误文字；仅凭 150 不能确定原因。不需要删除登录凭据或应用数据。

独立的 AI 配置网页

安装后选择「配置 AI 接口」，脚本会打开当前项目专用的本地配置网页。ChatGPT 账号页签提供官方浏览器登录或设备码；API 页签支持命名方案、自选服务商 API Base URL、API 协议、密钥和准确模型 ID。Codex 自定义接口采用 Responses，OpenCode 可用 Chat Completions、Responses 或 Anthropic Messages。多个方案可以保存并切换默认值。

编辑已有方案时密钥留空会保留；读取模型列表是可选操作，不会发送对话。点击「完成配置」关闭配置服务并返回菜单，然后启动应用。网页关闭按钮本身不会停止服务。已运行的应用需要重启，并新建对话使用新的默认方案。默认 OpenCode 或自定义 Codex API 无需先登录 ChatGPT。密钥保存在项目内 local-secrets/api-keys，方案在 local-secrets/ai-config，不导入全局账号。

bash Saplingagent.sh --lang zh configure
bash Saplingagent.sh --lang zh configure --no-open

自动打开失败时使用终端打印的本地网址。详细说明见 AI configuration guide（英文）。真实账号登录、额度、模型工具调用和 Windows 真机流程需实际验收。

Claude Agent SDK

安装 / 更新会在项目内安装官方 SDK 及原生程序。选择配置 AI → API / 自定义服务商 → Anthropic · Messages，填写自己的 API 密钥、准确模型 ID 和基础网址（https://api.anthropic.com/v1 或兼容接口）。保存并使用，完成配置后启动应用。Claude 方案不需要 Codex 登录或全局 Claude 安装；不提供 claude.ai 订阅账号登录。已有对话保留原来的引擎与模型。配置与认证限制。

首次安装选择 Git 存放方式

客户默认下载 release 分支。安装时选择：仅本地（有本地 Git 历史，无远端）、自己的仓库（输入已创建的仓库地址，作为 origin）、跟随作者 release（upstream）。Git 子菜单仅有 1、2、3，回车默认选 1。选 1 时，无仓库则自动新建本地 Git 仓库；已有仓库则移除全部远端链接，包括自定义 origin、upstream、mirror，保留文件、暂存修改、提交历史和当前分支 / 历史版本。选 2 会将 origin 新建或更新为用户填写的远端地址，保留其他非作者远端。新目录默认建立真实 release 分支，可自行配置。

先停止应用，再选择菜单 5「Git / 存放配置」，或运行 bash Saplingagent.sh --lang zh git 修改选择。配置保存在本地 .git/config，重装 / 修复保留当前选择。安装不会自动 pull、push、创建远端仓库或提交 PR，选 1 删除全部远端配置，选 2 按用户填写的地址更新 origin；不会重置源码或丢弃未提交修改。Git 子菜单移除 4 和 0，主菜单的诊断和退出仍保留。旧版已保存的保留现有配置仍兼容重装。源码安装包不带 .git，用户选择后初始化；Mac 缺少 Git 时需安装 Apple 命令行工具（xcode-select --install），Windows 的 Git Bash 提供 Git。

跟随模式只获取上游历史，保留分发目录并基于实际源码提交建立本地快照。没有清单的 ZIP 必须与上游某个提交一致；无法识别或已修改的 ZIP 可选本地 / 自有仓库，或使用 Git 克隆。之后先执行 git fetch upstream 查看变更，再自行合并 git merge upstream/release，解决冲突、复核本地目标和任务记录后重启。安装 / 更新只处理依赖。分叉历史上的 pull 会停止，不会强制覆盖。

自动安装可设置 SAPLING_GIT_MODE=local、own 或 upstream；own 需要 SAPLING_GIT_REMOTE，可用 SAPLING_GIT_BRANCH 自选初始分支。网址不应包含密码或 token。Full Access 不变。
