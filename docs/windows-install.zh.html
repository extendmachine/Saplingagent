Windows 安装 Saplingagent

适用系统

主要目标是已更新的 Windows 10 1809+ Intel/AMD 64 位（建议 19045），PowerShell 5.1 或更新版本；也支持以 Windows 11 x64 或 ARM64 为测试目标。安装时自动检测原生 x64 或 ARM64 架构，无需手动选择；不支持 32 位 Windows。需要可写的本地文件夹，以及 Node、npm 和模型服务商的网络访问。当前开发验证在 Mac 上完成，Windows 真机验收仍待进行。

安装、配置和启动

  1. 解压整个项目文件夹，不要直接在 ZIP 内运行。
  2. 在项目文件夹打开 Git Bash。
  3. 运行下面的命令，选择中文。
  4. 依次选择「安装 / 更新」→「配置 AI 接口」→ Codex 登录 →「启动应用」。
bash Saplingagent.sh --lang zh

同一菜单可以配置 OpenCode 服务商和 API 密钥。目前启动仍要求已有的 Codex 登录。保持终端窗口打开；网页默认 http://127.0.0.1:5173/。正常停止请按 Control+C。

文件和账号

Node24.21.0 校验官方 SHA-256 后安装到 .runtime/；Codex0.146.1、OpenCode1.19.0 和锁定依赖也安装在项目内。无需 WSL、全局 Node 或 Codex 桌面应用。不修改系统 PATH、注册表或永久执行策略；请使用 Git for Windows 自带的 Git Bash；Windows 系统工具由 .sh 内部调用，不需要手动执行 PowerShell。

使用自己的模型账号；登录不等于免费或保证额度。Codex 凭据在 local-secrets/codex/，OpenCode 在 local-secrets/opencode/。权限保持当前系统用户 Full Access，不新增目录保护、不提升管理员权限。分发时必须复制完整文件夹，单独复制 .sh 不够。

切换版本和重启

Windows 安装需要 Git for Windows 提供的 Git Bash；聊天不要求创建 Git 仓库，分支和版本控制需要实际 Git 仓库。ZIP 源包没有 Git 历史和三个开发分支，需要测试切换时请使用 Git 检出目录。先选择版本，再点击 Restart app；Restart backend 保留前端。故障恢复页面为 /__saplingagent/runtime。

请先完成正在进行的对话和写入。Windows 使用本次启动进程的 PID 树停止服务，属于强制结束；不能撤销已发生的副作用。强制关闭父进程、断电或另行脱离的程序不能保证清理。修改启动器、管理器或端口时，要退出终端中的服务并重新启动。

排错和真机验证

诊断使用 doctor；修复安装使用 install --repair；设备码登录使用 login --device-auth。安装被打断后，确认安装进程已经停止，再删除残留的 .runtime/windows-node.lock 或 windows-install.lock，重新安装。建议较短的本地路径，避免 Windows 路径长度问题。

请在 Windows10 真机依次验证：安装、登录、发送和停止消息、刷新恢复、配置 OpenCode、修改一个临时应用文件、切换 Git 版本并重启前后端。这些真实模型步骤尚未在当前 Mac 环境执行。

安装前出现退出码 150

旧菜单可能在后台启动 Windows 终端桥接，导致尚未检测设备就被终端控制信号停止。新版 Windows 操作在前台执行，安装和诊断直接启动 PowerShell。请更新完整项目文件夹再重试。应先看到“正在启动 Windows install（PowerShell）”，再看到“Windows 安装器已启动”，然后检测设备。若仍失败，在 Git Bash 运行 bash Saplingagent.sh --lang zh install，保留此前的启动和错误文字；仅凭 150 不能确定原因。不需要删除登录凭据或应用数据。
