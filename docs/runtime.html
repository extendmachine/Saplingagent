运行与Full Access

启动

Node≥24.11、npm、官方Codex CLI，本机Codex0.146.1。依赖归项目，默认网页127.0.0.1:5173，三个回环后端端口4310/4311/4312。

node scripts/install.mjs   # 首次依赖准备
node scripts/dev.mjs       # 统一启动
node scripts/login.mjs     # 需要本项目登录时

已有本机Codex登录可在项目无认证时复制到local-secrets/codex，不覆盖原项目认证或全局配置；浏览器不持有内部token。未知端口占用会停止启动；Ctrl+C结束本次服务。front每日生命周期日志保留30天，原始诊断在终端。

用户选择的权限

当前为Full Access：Codex danger-full-access + approval_policy never，seedagent MCP执行默认approve；原生文件与shell启用。backend、MCP、Skills、基础聊天、main、配置、依赖、规则和其他当前系统用户可访问路径均无应用级文件保护，可用绝对或相对路径。权限为当前系统用户，未自动提权root。

取消强制候选编译、AST/YAML/hash门槛与逐次确认；检查由具体需求决定。当前页面与用户已生成内容保留，本次没有恢复初始空白布局。HTTP仍在回环且内部Bearer用于识别服务。

对话和工具

浏览器同源/api → Agent → 官方Codex App Server，SSE展示真回复及工具状态。会话持久化、请求去重、刷新重连、重启续聊、停止/错误重试沿用。当前实际模型gpt-5.6-sol/medium，配置首选不可用时选择模型目录默认。

15个MCP工具：读取文件/上下文、直接写入和删除文件、执行命令、可选候选与快照、偏好以及Skills发现。workspace_write_file/delete_file/run_command可直接操作；page_propose只生成ready候选，page_apply执行，page_rollback由用户主动请求。修改工具尝试登记根AI_TASKS，但登记失败不会挡住操作；只读聊天不登记。

三个Skills提供页面修改、官方资料研究与可复用流程编写，可被AI修改；合法frontmatter是Codex发现格式，不是写入权限门槛。后端/MCP源码与依赖也可修改，运行进程重启后加载。

页面快捷能力

左侧项目文件栏可展开全部目录、查看和编辑文本文件，并从“…”复制绝对地址；保存使用完整文件hash避免覆盖外部修改，二进制、截断内容和符号链接保持只读。详情编辑器关闭后回到原单页聊天，窄屏文件栏使用抽屉。

左上“截屏”按钮调用浏览器原生getDisplayMedia选择器。用户选择屏幕、窗口或标签页后，页面抓取单帧并直接下载带时间戳PNG；图像不上传后端。浏览器安全策略要求每次由用户发起并选择捕获来源，网页不能静默绕过。

用户主动回退

文件工具尽力保存原件，可选候选保存到snapshots/app-builder；快照失败不阻止直接文件操作，只有实际可用的记录才可恢复；用户需要时查看page_changes并调用page_rollback，可覆盖后续修改。不自动回退或阻止新的写入。任意shell、Codex原生文件操作及外部副作用不保证进入快照，也不保证完整可恢复。Stop请求中断当前turn，不撤销已发生的操作。
