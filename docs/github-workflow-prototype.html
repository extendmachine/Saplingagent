SAPLINGAGENT · APPLICATION PROTOTYPE

From a GitHub link to your application

This is an interactive frontend prototype. No source is downloaded, no AI inference runs, no application is generated and nothing is uploaded to GitHub.

Try the five steps

  1. Import. Enter a GitHub repository, branch or file URL, or select the video-tool example. The path under projeccts/ is a proposed location.
  2. Understand. Read the illustrative overview and switch between License, Directory, Dependencies and Issues. Real source text and provenance will replace these placeholders after backend integration. Use the review-state selector to inspect access, license and compatibility blockers.
  3. Select. Choose capabilities, name the application and describe desired improvements. Required example dependencies follow the selection. At least one capability and a nonblank name are needed.
  4. Upgrade. Inspect the scope, separate source/output paths and planned checks. The delivery screen is a placeholder, not a running generated application or passing test result.
  5. Publish. Enter your own destination repository and preview the checklist. The source repository cannot be used as the destination. Ownership, write access, existing contents and the publication commit remain unverified; upload stays disabled.

Source and output

The requested directory name is projeccts. Future downloads belong in projeccts/owner--repository/source; generated applications have a separate saplingagent directory. Nothing is created by this prototype.

What is preserved

The existing language selector, Settings/Help entries, AI conversation and page-inspection bridge remain. On a narrow screen, collapse the AI chat using its arrow to see the workspace; reopen it from the edge tab. New project resets only the current prototype selection after confirmation. Refresh starts the prototype over.

What comes next

Repository/ref resolution, project-local downloads, actual source and license analysis, feature extraction, Agent execution, verified output and authenticated destination publication. Any repository link can be assessed; source availability, applicable licenses and runtime requirements determine feasibility. Full reproduction is not guaranteed. No new backend or paid service has been enabled.

从 GitHub 链接，到你的应用

当前仅为前端交互原型，不会下载源码、调用 AI、生成应用或上传 GitHub。

依次体验：输入链接 → 阅读项目介绍与许可证、目录、依赖和 Issues → 勾选功能并填写改进要求 → 预览升级方案与交付占位 → 填写自己的仓库并预览发布清单。

源码与生成应用计划分别放在 projeccts/owner--repository/source 和 projeccts/owner--repository/saplingagent。原型没有创建这些文件夹。异常状态与功能信息均标注为示例。

中英文切换沿用现有设置；窄屏下可先收起右侧 AI 对话。新建项目只重置当前原型选择，刷新页面会重新开始。真实仓库处理、适配验证及发布将在后续实现，不能把原型中的点击当成真实操作完成。
