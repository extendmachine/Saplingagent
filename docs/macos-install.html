Install and connect Codex on macOS

Requirements

macOS 13.5 or later; Apple Silicon or Intel; a writable folder; internet access to Node.js, npm and OpenAI. ZIP installation needs no global Node, Homebrew, Xcode or Codex desktop app. Git is optional for running chat and required for the Git controls/repackaging.

Your own Codex account must have the relevant model access and available quota. Installer architecture selection is supported for both Mac architectures; this release's local checks run on Apple Silicon. Intel/Finder/OAuth interaction requires validation in the corresponding environment.

One launcher

Open Terminal in the extracted application folder and run:

bash Saplingagent.sh

Choose English or 中文; Enter defaults to English. To open Chinese directly: bash Saplingagent.sh --lang zh. See the 中文安装说明. Finder double-click normally opens an editor for .sh files. Running with bash needs no chmod; direct ./Saplingagent.sh requires an executable file. Use Bash rather than sh.

The installer verifies official Node 24.21.0 checksums and installs local Codex CLI 0.146.1 plus locked dependencies, without sudo or global credential import.

Codex stores project login in local-secrets/codex/. OpenCode provider credentials stay under local-secrets/opencode/; custom endpoints/models follow the provider configuration guide. The current startup still checks Codex login; select OpenCode before the first message of a new conversation. No existing conversation switches engine automatically.

What the integration does

React → local agent-runtime → codex app-server --listen stdio:// → project MCP → workspace/app-builder. Agent-runtime initializes JSON-RPC, checks the account/model catalog, creates/resumes threads and streams events to the browser. It configures 15 MCP tools and discovers three project Skills automatically.

No manual Codex desktop MCP configuration is needed. The project wrapper selects CODEX_HOME and local binaries. Existing internal seedagent/SEED identifiers remain compatible. Services bind loopback ports 5173, 4310, 4311 and 4312; public settings are in config/runtime.json.

Full Access permits files/commands accessible to the current OS user, without root elevation, directory allowlists or automatic rollback.

Account costs and commercial use

The local server has no separate server fee; model usage requires your own authentication/quota. The default installer uses ChatGPT login. Codex also supports API-key authentication billed separately from ChatGPT subscriptions, but this Mac launcher does not include a dedicated API-key setup flow. Installation/login/model discovery does not prove inference access. Start/Doctor send no model prompt.

Check authentication and current usage limits. No free-tier entitlement is promised.

Saplingagent's license restricts commercial use. In addition, the current local Codex authentication is not permitted for commercial or hosted services. Commercial product release requires separate project permission and an eligible Sign in with ChatGPT integration.

Diagnostics and recovery

bash Saplingagent.sh doctor
bash Saplingagent.sh install --repair
bash Saplingagent.sh logout
bash Saplingagent.sh start --no-open

Doctor reports installation/login/runtime status without displaying credentials or requesting inference. Repair preserves source, authentication and business data. Logout removes this project's login; it preserves application files and conversations.

Switch versions and restart

Select a branch or historical version, then choose Restart app to reload frontend, backend, Codex App Server and MCP. Restart backend retains Vite. Busy AI and file operations refuse restart.

The persistent gateway serves GET /api/runtime/status, POST /api/runtime/restart with optional {scope: "all" | "backend"}, and the recovery page /__saplingagent/runtime. The gateway stays available through frontend/backend failure. Generation advances after all selected services and authenticated Agent/MCP are ready.

Public frontPort5173, internal vitePort5174, manager4314. Optional PDF starts only when its selected source exists. First adoption, manager/launcher or port changes require stopping the old launcher and starting the Mac launcher. New dependencies must be installed. Current UI restores an unsent draft; older versions may not. Legacy direct callers are not covered by gateway operation accounting. No automatic chat resend, source rollback or credential reset.
