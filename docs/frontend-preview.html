The current interface

A single chat page

The application begins with one conversation and an input area. The compact header offers language selection, Help and a top-right Settings link opening the current project runtime page in a new tab, preserving the chat and unsent drafts. The main page has no embedded restart/kernel buttons or bottom version indicator. The AI adds other features only when requested. The optional GitHub workflow prototype remains in the source but is not mounted on the default page. The interface supports English and Simplified Chinese; conversation content stays in its original language.

Assistant messages render Markdown with GFM tables, strikethrough and task lists. Code-block tables retain their literal text. The page shows model/tool activity, local errors, Stop, Retry and New conversation. Refresh can restore saved conversations without automatically resending prompts.

Open the running application · Settings and runtime controls

Progress and updates

The default total-turn deadline is disabled. A 10-minute inactivity reminder uses the last effective model/tool progress; it leaves the turn running. Heartbeats and polling do not extend progress. Use Stop to interrupt manually. Source changes may show a refresh reminder; backend/MCP/dependency changes require a restart.

Historical screenshots

Images under docs/images are archived evidence from earlier development, including Chinese conversations and abandoned layouts. They are not current English UI previews or default application content. The original binary evidence is retained rather than rewriting past user messages.
