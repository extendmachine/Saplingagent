A local workspace for building and evolving software with AI. Start with one chat, shape the interface and extend the tools in your own project.

Development and public release

This is the main development/testing branch. Shared changes land and are checked on main before a requested release promotion. A main-only task does not update release.

The release branch is the public default and customer source. Videos, application cases and showcase images live there: English introduction and demos · 中文介绍与演示. Preserve that presentation when promoting code.

Folder ownership

The complete application folder contains all project-owned code, rules, Skills and launcher helpers; it does not depend on another developer checkout. Model services and locally installed dependencies remain declared requirements.

Full Access remains available. Normal edits are recommended within this folder; a customer can explicitly request work on external code. Every final conversation reply is instructed to include a completion-review receipt reporting actual work and checks, including read-only replies.

Start on macOS

  1. Extract the complete application into a writable folder.
  2. Open Terminal in the application folder and run bash Saplingagent.sh; select English or 中文.
  3. Choose Install / repair dependencies, Configure AI, then Start app from the same menu.

Configure AI offers Codex account login and OpenCode provider/API-key setup. Diagnostics is available from the same launcher. See the installation guide for details, or read the 中文安装说明.

Windows installation

A native Windows10/11 x64 and ARM64 Bash menu installs this complete folder and configures Codex/OpenCode. Windows10 x64 is the requested target; real Windows login/model/restart acceptance remains pending. See Windows guide / 中文 Windows 安装说明.

What is implemented

Streaming chat with GFM Markdown tables, local session recovery, stop/retry/new conversation, progress-based inactivity reminders, independent kernel upgrades/restart controls, 15 MCP tools and 3 project Skills. The default whole-turn deadline is disabled. Full Access follows the current OS user's permissions.

App Server runs as a local Codex subprocess, not a hosted Saplingagent model service. Frontend code belongs in front/, backend services in backend/, and human guides in docs/. Private data and credentials stay in the application folder and are excluded from source delivery.

License and current limits

Project-owned source uses MIT. Commercial use, modification and distribution are permitted with copyright/license notices and the upstream repository URL retained. The current local Codex login is not a commercial or hosted authentication integration.

Long-term automatic layout adaptation remains a goal requiring real usage evidence. Cloud synchronization, Linux installers and a signed native Mac app are not implemented.

Configure AI

After installation, the Bash menu opens an independent local account/custom-provider setup page. See the AI configuration guide.

Claude Agent

The official Claude Agent SDK is also available as a local engine. Install/update, then choose Configure AI and the Anthropic preset. Use your own API key or compatible gateway, or configure a personal subscription token generated with the official CLI. Project MCP, Skills and resumable streaming conversations use the existing single-chat page. Claude and custom API setup.

Restart all project services

Open Settings from the chat header to reach the runtime page. Restart app there reloads the frontend, backends and newly created services. The AI adding an independent process also registers its startup,dependencies and readiness. Project service startup.

Independent kernel management

Update shared platform functions separately from your application Git history. Preview conflicts, keep an owned-source backup, and recover explicitly if compatibility breaks. Kernel update and recovery.

Current kernel version:0.9.8

Saplingagent uses one kernel version from kernel/manifest.json. The current setup, runtime/kernel management and installer show Kernel0.9.8; the chat page uses a Settings link instead of a version footer. There is no separate product version. For old0.90/0.91/0.92 updater numbers see one-time migration; preserve local conflicts and backups.

Save, restart, then export

Finish the project name/icon/folder and AI settings before choosing Save settings & restart. Wait for the external helper to finish the directory move and verified service restart, then choose Export app. See the launcher guide.

Project-relative configuration storage

Temporary configuration runs in a session-owned ../sapling-config-… directory beside this project. The terminal prints its location; Finish setup waits for exit before cleanup. Persistent settings, caches and outputs remain local. Directory layout and process locks.

External AI / MCP

Connect your own AI client through local stdio MCP with current-OS-user Full Access. External-only setup needs no built-in model account. Setup, client JSON and maintenance.
