Grow your application through conversation

Saplingagent starts with a local chat page. Describe an application or feature, and the AI can create or adjust the React frontend, local backend, MCP tools and reusable Skills.

Start on macOS

  1. Extract the complete application into a writable folder.
  2. Run bash 1-Install.command.
  3. Run bash 2-Login-Codex.command and log in with your own account.
  4. Run bash 3-Start-Saplingagent.command and open the local page.

See the installation guide for diagnostics, account eligibility and costs.

What is implemented

Streaming chat with GFM Markdown tables, local session recovery, stop/retry/new conversation, progress-based inactivity reminders, Git version controls, 15 MCP tools and 3 project Skills. The default whole-turn deadline is disabled. Full Access follows the current OS user's permissions.

App Server runs as a local Codex subprocess, not a hosted Saplingagent model service. Frontend code belongs in front/, backend services in backend/, and human guides in docs/. Private data and credentials stay in the application folder and are excluded from source delivery.

License and current limits

Project-owned source uses PolyForm Noncommercial 1.0.0. Commercial use requires separate written permission. The current local Codex login is not a commercial or hosted authentication integration.

Long-term automatic layout adaptation remains a goal requiring real usage evidence. Cloud synchronization, Windows/Linux installers and a signed native Mac app are not implemented.
