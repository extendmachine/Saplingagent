Saplingagent Windows installation and AI setup

Product0.9.2 · independent kernel0.91/schema3. Fresh users receive the release snapshot without Git metadata. Installation never initializes Git, connects remotes or asks for storage.

Install locally

Use macOS Terminal (13.5+, Intel/Apple Silicon), or install Git for Windows and use Git Bash on Windows10/11 x64/ARM64. CMD/PowerShell do not directly run Bash; WSL/Linux is not this native Windows path. Node and dependencies stay in this folder.

curl -fsSL https://raw.githubusercontent.com/extendmachine/Saplingagent/release/install.sh | bash

Alternatively extract a release ZIP and run:

bash Saplingagent.sh
  1. 1 Install / repair dependencies: preserves application source and existing customer Git.
  2. 2 Configure AI: opens an independent page for your own Codex account or Codex/OpenCode/Claude API scheme, including custom API URLs. Codex can import local/uploaded auth.json; Claude imports API credentials only, not subscription login.
  3. 3 Start app: use its actual printed local address; occupied ports advance.4 Diagnostics,6 Kernel management,9 Language,0 Quit.

If browser opening fails, run bash Saplingagent.sh configure --no-open and use the printed local URL. Account access, quotas, actual model readiness and network depend on your provider.

Upgrade the kernel from the page

Kernel → Check for kernel update → Upgrade kernel & restart. A separate progress page survives the old runtime stopping, backs up/applies core, repairs only core dependencies and starts the complete app at its actual selected port. Application pages, MCP, Skills, services, application dependency declarations, data, credentials and existing Git are preserved. Failure offers explicit retry or manual source restore; no automatic rollback.

Transition from0.9.1

The old schema2 prototype cannot automatically cross this ownership boundary. Download0.9.2 into a new folder, retain the original and deliberately migrate your application/data/configuration. Do not blindly overwrite credentials or regenerate the old baseline. Future compatible schema3 kernels support the web upgrade path.
