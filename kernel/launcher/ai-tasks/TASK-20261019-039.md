## Scope and design

Explicit user request puts temporary setup beside the project and derives all
Saplingagent-managed settings/helpers/cache outputs from that project, with process
locks. Canonical absolute paths may identify the actual OS-owned root internally.
No Agent permission sandbox or global account mutation is introduced.

Modified kernel/launcher source/native/helpers/tests/contracts and the macOS Bash
and Windows PowerShell Node bootstrap. Parent owns CLI/common storage/manifest/docs;
sibling_configuration owns capsule sessions/controller. No changes to main/release,
customer folders, root index, credential contents or other task source.

Legacy finalization derives only a direct sibling, creates private temporary/cache
folders and checks directory/job identity before cleanup. No OS-temp fallback.
Native app/bootstrap prepare local temporary directories before child tools. Build
storage resets inherited B caches and rejects symlink/junction redirects before
creating descendants. Pinned Go telemetry uses private off state verified against
local Go1.27.2 source. Actual global HOME is retained for read-only account discovery.

Native compilation serializes through compile and kernel-operation leases, refuses
foreign setup/install/maintenance state, permits B only with explicit setupId and
same PID, and removes only owned leases after closing handles. TASK038 passes
setupId and checks compile leases before moving. Source/launcher replacement and
stale-lock recovery remain explicit.
