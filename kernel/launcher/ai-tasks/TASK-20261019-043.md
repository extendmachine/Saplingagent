## Scope and interface

`build.mjs`, `native/*`, native tests, dependency/reference notes. A built-in
stay-open AppleScriptObjC applet is the macOS bundle executable; the existing
CGO-free Go executable is its helper. The applet's PID and UUID accompany
`--dock-start`, `--dock-open`, `--dock-status`, `--dock-stop` to the public Node
entry owned by TASK044. Start/open run asynchronously; status is queried during
startup. Normal Quit stops before exiting; stop failure leaves the app visible.
`handoff` permits native exit without stopping the cluster again. No compile-time
developer path, global runtime/compiler, business service or AI permission change.

Go passes bridge stdout/status unchanged. Initial Node preparation uses an owned
bootstrap process group and cancellation; a subsequent Node action receives a
direct graceful signal and is awaited. Status/stop never reinstall Node. Missing
Node with potentially live owned runtime discovery causes an explicit failure.
Existing default helper launch and Windows bootstrap retain prior behavior.
The root coordinator adds compile/move guards using the new public Dock close
contract after integration; this worktree does not own that lifecycle bridge.

## Validation

Actual system osacompile, local pinned Go and ad-hoc signing were used in an
isolated Unicode/quote-containing fixture. Tests cover regular activationPolicy0,
reopen same PID, normal Quit invoking Stop and exiting, signature after Quit,
handoff exit with no second Stop, bridge error exit propagation, cancellable
missing-Node bootstrap, controls without installation, and refusal to claim stop
with live runtime discovery. Existing native bootstrap test also checks real
macOS relative startup and Windows x64/ARM64 cross-compilation. All fixture
processes are stopped before removing their project directories.

Native shell self-checks are separate from the integrated TASK044 bridge/real
cluster checks and owner acceptance. Windows native operation and real model
accounts are not tested by this task. No customer source/runtime is modified.
