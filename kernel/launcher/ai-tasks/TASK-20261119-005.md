# TASK-20261119-005 — Reduce idle status polling

The macOS Dock launcher checks for project maintenance locally every two seconds, uses the authenticated status helper at a 20-second interval while settled, and checks promptly while starting, reopening or quitting. The browser runtime status page suspends automatic requests while hidden and refreshes on return.

On macOS ARM64 with Node 24.21.0, 15 launcher integration, native Dock and runtime status tests passed. The native fixture verifies no repeated status helpers during a 4.5-second idle sample and a timely response to a maintenance request. Existing native apps need a rebuild to receive the AppleScript change.
