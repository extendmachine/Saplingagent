# Saplingagent kernel

Independent platform package, not a new persistent backend. Versioned ownership/compatibility manifest, read-only discovery, explicit update planning and source backup/recovery. Node built-ins only, project-local runtime. Kernel owns platform functions; business App/features/services and user records stay independent. Source layout remains compatible with existing entrypoints; package membership provides separate maintenance without moving all modules or restricting Full Access.

CLI: bash Saplingagent.sh kernel (menu), kernel status/check/update/restore <id>. No Git operation or remote setup, including own/local storage. Official source release is pinned before download. No credentials used or uploaded. Contracts: CONTRACT.md; deployment/recovery: DEPLOY.md; official sources: REFERENCES.md. Maintainer manifest generation is explicit, never run automatically against a customer's modified source.
