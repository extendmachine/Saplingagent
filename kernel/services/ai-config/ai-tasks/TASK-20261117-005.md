# Configuration save and credential recovery

Codex, 2026-11-17. Repair17-config is a detached service candidate from main
9e6939d. The configuration service now binds key reuse to the original origin,
isolates unavailable credentials by profile, and publishes account/key, ledger
and connection metadata as a recoverable transaction. The existing file layout
and provider IDs are preserved. Bilingual setup identifies changed origins and
damaged Codex login data. Engine catalog queries and settings state observe one
generation. Explicit import can replace damaged account files.

Verification used synthetic fixtures on macOS with project Node 24.21.0.
The focused configuration/engine/setup/capsule suites passed 187 tests,
including a deliberately interrupted subprocess, per-file rename failures,
old binding and catalog rejection, a concurrent status read, a damaged account
with invalid UTF-8, and individual missing/linked/nonregular scheme files.
The setup production build and typecheck passed. No real model calls,
customer credentials, public release or Windows-native acceptance.
