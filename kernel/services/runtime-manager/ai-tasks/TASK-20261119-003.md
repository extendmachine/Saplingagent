# TASK-20261119-003 — Optional static frontend serving

Codex, 2026-11-19. Public rules 2026-11-03.1. The authoritative owner and
integration record is in the coordination worktree. Developed in opt19-static
from maintainer main c27c475. Kernel version 0.9.9.

## Delivery

The project runtime configuration can select an in-gateway static frontend.
The project's own build produces its normal public directory on cold and full
restart, with an atomically selected, session-owned snapshot for concurrent
requests. Development HMR remains the default. Static mode keeps authentication,
runtime recovery, per-project ports and the streaming Agent API. The service
contract, English/Chinese deployment instructions and HTTP status documentation
describe the fields and recovery. The existing locked serve-static 2.2.1 is
declared as a direct optional-mode runtime dependency of the kernel.
