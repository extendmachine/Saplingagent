# Public language contract

TASK-20261023-010, 2026-10-23. English (`en`) and Simplified Chinese (`zh`) share stable keyed namespaces. `public.mjs` exports dependency-free normalization, safe placeholder interpolation and error explanations; `public.d.mts` describes browser TypeScript consumers. Application messages stay in `front/`; setup/launcher/runtime namespaces stay in the kernel. Adding a locale requires matching namespace keys, placeholder parity, rendered checks and language selection updates.

Project preference is `config/ui-language.json`, schemaVersion1, language en|zh. It is customer-owned, ignored, excluded from source delivery and not overwritten by kernel updates. `store.mjs` holds the existing configuration-write lease (also used during rename), checks managed directories/regular files, and atomically replaces this single small file; it does not initialize a project or edit credentials. Read fallback: missing/malformed/unsupported file -> caller's normalized locale (otherwise en); real filesystem errors remain errors. Explicit setting is stored; no inferred browser locale is silently written. CLI explicit --lang overrides a saved choice; saved choice overrides locale fallback. Browser choice persists across ports via the project API. Denied storage must not break chat.

GET /api/runtime/language and protected GET /api/config/language return `{language,supported:["en","zh"]}`. POST accepts only `{language:"en"|"zh"}` and returns the same object after persistence. Existing Host/Origin/authentication checks remain. Invalid input400; shared configuration/runtime busy409; disk failure503. No model request, process restart, credential access or conversation rewrite. Runtime language writes hold the existing gateway-write drain count from request-body reading through actual persistence or failure, including client disconnect; maintenance cannot terminate a pending preference save. Stale initial reads cannot replace an explicit UI choice. Same-origin browser language events are presentation-only and contain no secrets.

Errors retain stable protocol codes and sanitized raw technical details, alongside localized summary/action. User conversation data, model output, paths, provider names and IDs are not translated. UI language is independent from AI output language. Public helper imports are a supported boundary, not private cross-service imports. No third-party dependency, directory restriction or added tool approval.
