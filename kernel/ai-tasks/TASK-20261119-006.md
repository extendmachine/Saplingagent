# Explicit and detected installer environments

The pre-Node router selects a single macOS, GNU/Linux or Windows bootstrap.
A leading or trailing --platform option takes precedence over SAPLING_PLATFORM.
An explicitly selected auto performs detection and bypasses the interactive
prompt. An unknown system or unsuccessful uname probe selects Linux. An
unknown user-supplied target reports a usage error before a bootstrap runs.

During an interactive installation with no explicit platform, Enter accepts the
detected environment or Linux fallback; the user may choose another environment
or cancel. Noninteractive installs and other actions proceed without a prompt.
The normalized platform is exported to the selected installer. Installer failure
returns its original status; the router never retries on another operating system.

macOS Bash 3.2 tests exercised explicit CLI and environment options, failed OS
detection, exact bootstrap status, Windows Git Bash routing using test doubles,
and real pseudo-terminal install prompts. The router, launcher-menu and device
checks passed 28 tests, with two platform-conditional skips.
