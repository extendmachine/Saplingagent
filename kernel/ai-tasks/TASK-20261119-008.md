index. This change concerns only the selected macOS path. The main launcher
owns the OS selection and its Linux fallback.

The Mac bootstrap verifies macOS 13.5+ using the system product version or
SystemVersion.plist. The bootstrap and Codex compatibility wrapper share a CPU
probe that recognizes ARM hardware and translated processes before selecting a
Darwin arm64 or x64 package. An unidentified CPU stops before download. The
selected Mac installer also stops on a foreign host before writing its runtime
directories. The Windows tests now exercise the actual standalone PS1 and its
localized messages. The macOS fixture copies the required device helpers.

On a physical Apple Silicon Mac, runtime-only accepted the existing matching
Node with uname and sw_vers disabled, using the actual plist and sysctl.
The installer suite passed 16/16, native bootstrap subset 2/2, and device suite
5/5, including actual PowerShell architecture and foreign-host tests. Synthetic
cases cover Intel, Rosetta, unknown CPU and missing version. In Debian ARM64 a
manually invoked Mac installer stopped on a read-only project before download.
No native Intel or Windows machine was tested, and no AI account was used.
