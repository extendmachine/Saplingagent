# GNU/Linux headless projects

The Linux terminal installer accepts glibc x64 and ARM64 with Bash, flock and the
pinned official Node/npm distribution. AI-only setup uses the external sibling
capsule. A first setup finishes before the terminal starts the application. A
configuration change for a running project resumes that runtime. Tools can use
the Linux per-user library or a movable portable copy. The launcher uses the
project's resolved ports and owned processes. See docs/linux-install.html.

An isolated Debian 12 ARM64 container installed the kernel and app from a clean
source snapshot. Its AI setup served HTML, saved external-only MCP, exported a
Linux Node command, finished cleanup and started the application. The gateway
reported ready, served the app, and acknowledged stop. A real Codex App Server
performed its initialization handshake without credentials or paid requests.
The targeted Linux suites passed 90 tests with 3 conditional skips. Emulated
Linux x64 passed both device/bootstrap tests, including two projects sharing
Node, switching to portable, moving a project and switching back. The macOS
installer subset passed 20 tests with the Linux-only execution case skipped.
The coordinating worktree owns the combined manifest and main integration.
