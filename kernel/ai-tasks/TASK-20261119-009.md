# GNU/Linux native runtime installation

On a first installation, the Linux bootstrap reuses a matching Node/npm distribution or downloads only the official tarball for the detected CPU. The selected library/store has a per-version flock and an atomic publish step after SHA-256 and executable validation. A portable installation keeps its downloads inside the project. System selection and language are handled upstream by the common Bash entry.

Two concurrent installations in separate fresh directories on each of Linux ARM64 and emulated Linux x64 downloaded one official checksum list and one matching tarball, then both ran Node 24.21.0 with npm 11.19.0 from the same location. The targeted Linux tests passed on both architectures, including failed-checksum cleanup, concurrent requests, portable relocation and switching back to the shared runtime.
