## Decisions

- Call the public `launcher/public.mjs` `closeDockForMaintenance(root)` contract
  before stopping the runtime or acquiring the configuration leases. The native
  startup worker may itself own an operation lease, so it must be cancelled and
  released before setup attempts that lease.
- Recheck native close while holding the setup/kernel leases immediately before
  the offline check and folder move, covering an app launch in the intervening
  window. Existing runtime stop/drain, same-parent move, root rebinding, native
  compilation and B-to-A cleanup behavior remain in place.
- Ownership refusal or exit timeout fails the job before rename/compilation.
  Existing saved settings and the actual project folder remain available for
  inspection/retry; B removes only its own acquired leases.
- The external capsule's automatic module closure includes the public interface
  and native-close implementation. No developer checkout/global dependency or
  new persistent business service is introduced.
- Opening settings alone does not close the Dock app. Save & build app performs
  the handoff; after Finish setup the user opens the new app normally.
