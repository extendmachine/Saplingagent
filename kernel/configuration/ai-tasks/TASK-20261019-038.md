  parent. No OS temporary location or caller-selected tempParent is supported.
- Schema2 sessions persist relative project/capsule names plus device/inode identity
  of both directories and their shared parent. Runtime root addresses stay resolved
  internally for ownership/API operations. Require regular directories and receipts;
  reject symlinks, non-siblings, replaced directories and mismatched sessions.
- A's startup and returning-A cleanup hold the shared kernel-operation lease,
  serializing stale management/cleanup lock recovery. Live, invalid, PID-reused or
  uncertain owners are preserved. Persist the spawned B PID before leaving startup
  so failed early bootstrap cannot be mistaken for an abandoned parent session.
  If PID persistence fails while the spawned child is alive, close the descriptor
  but preserve operation/management receipts, blocking automatic stale cleanup.
- B's temporary/XDG/npm/Node cache locations are capsule-local. Persistent settings,
  credentials and output remain in the project. Launcher task039 rebases returning
  A's environment to project-local locations.
- Same-parent rename never replaces an existing destination. Check native compile
  lease before and under operation/finalization leases; pass setupId to compiler
  so the launcher implementation can verify same-owner compilation.
- Finish waits for B exit, rechecks both matching receipts/identities, and deletes
  only the owned dead capsule. Old schema1 temporary sessions are preserved with
  an instruction to close their original setup page before migration.
- Add non-secret relativeDirectory to published/reused management addresses so
  root-owned CLI/UI integration can display the actual sibling location.
