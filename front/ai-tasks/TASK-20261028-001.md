## Design and behavior

Existing shared header/Settings/Help, language controller, independently mounted
chat and PageContextBridge retained. The requested spelling `projeccts` is retained;
reference `source/` and output `saplingagent/` paths are separate and illustrative.
All reports, trees, dependencies, features, delivery and publication summaries are
labelled samples. Arbitrary non-example repos use generic feature placeholders,
never attributed video-tool findings. Review-state examples demonstrate access,
missing repository, unidentified license and runtime assessment. No current
license text, source SHA, tests or publication success is fabricated.

URL intake accepts canonical GitHub HTTPS/SSH and known repo subpaths, rejecting
lookalike hosts, embedded credentials and invalid origins/paths. Actual ref
resolution is deferred and must preserve the user's intended source in backend
implementation. Feature dependencies/empty-selection/name requirements and
invalidation of downstream previews work locally. Target=source is rejected.
Final upload is disabled. Native dialogs cover flow explanation, reset and
publication review. Reset is scoped to prototype state; reload discards it.
No browser persistence of repository inputs or new credentials is introduced.
